4. **Grand Square boundary**: private sources mix Government District and Financial District naming near the district boundary. D23 records use a practical classification while precise jurisdiction remains to be validated.
5. **Source quality**: community-listed services (Capital Bookshop, Kodak Photo House, Fawaz) and Habib Pharmacies are candidates requiring direct phone/site or field checks. They are not operationally endorsed.
6. **Temporary Hajj appeals**: November 2026 announcement establishes a time-bound appeals service, not unrestricted general-purpose opening hours.
7. **Out-of-scope exclusion**: Afreximbank's official new headquarters describes the Diplomatic Zone, so it is not included under Financial District despite conflicting secondary media.
8. **Data-governance improvement**: previous missing Entity Code values were repaired only when an existing numeric Place ID and Arabic name exactly matched `data/exploration.json`; all 107 matches passed. Remaining slug omissions were matched and completed by Entity Code.
