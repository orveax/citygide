# BR-03.1 — Existing Palette Refinement

Status: Draft PR for visual acceptance; not production deployment.

## Design decision

Keep the existing **Ink + Coral + Warm Neutral** brand identity. Do not switch to the blue exploration palette. The signature coral `#ED6A4D` remains available for decorative accents, oversized hero display and brand marks; use accessible `#C24A32` for white-on-coral controls and small foreground emphasis.

## Core tokens

| Role | Token | Value | Notes |
| --- | --- | --- | --- |
| Ink | `--ink-900` | `#242736` | Primary text |
| Navy | `--navy-900` | `#1E293B` | Strong surfaces |
| Signature coral | `--coral-500` | `#ED6A4D` | Brand signature, not normal-size white-on-coral text |
| Action coral | `--accent-action` | `#C24A32` | White text AA contrast ~4.86:1 |
| Action hover | `--accent-action-hover` | `#A83E2B` | Stronger contrast |
| Accessible muted | `--text-muted-accessible` | `#667080` | White background contrast ~5.01:1 |
| Warm tint | `--coral-100` | `#FFF0EA` | Background only |
| Canvas | `--neutral-100` | `#F8F9FC` | Light surface |
| Border | `--neutral-200` | `#E9EBF0` | Dividers |

## Brand scale (50 → 900)

`#FFF7F3`, `#FFF0EA`, `#FBD7C9`, `#F7AE98`, `#F18567`, `#ED6A4D`, `#D9573C`, `#C24A32`, `#A83E2B`, `#822F23`.

## Semantic state colors (independent of brand)

- Confirmed: foreground `#235B44`, background `#E7F5ED`.
- Under review: foreground `#765018`, background `#FFF5DF`.
- Unknown / not verified: foreground `#4E6279`, background `#EAF2F8`.

State should always include visible text, not color alone. These are design tokens only; BR-03.1 does not change verification logic or content labels.

## Scope and acceptance

- Target only palette variables and text-bearing primary controls in CSS; preserve layouts, copy, icons and data.
- Check desktop/mobile, hover/focus, Arabic text, light backgrounds and directory result cards.
- Confirm normal-text contrast >=4.5:1 and large text >=3:1, including control labels.
- Check that semantic badges never communicate verification status solely by color.
- Dark-mode design is intentionally deferred until a dedicated implementation/acceptance phase; no unsupported UI toggle.
- Keep the PR draft until visual QA and approval. No automatic production publish in this phase.
